# CAFE GREEN

架空のカフェを題材にした、HTML・CSS・JavaScriptのLPです。
ビルドやパッケージのインストールは必要ありません。

## ファイル構成

- index.html：ページ本文、ナビゲーション、デモのお問い合わせフォーム
- style.css：色、余白、レイアウト、スマートフォン対応
- script.js：スマートフォン用メニュー、フォームの入力確認、年号、画像の代替表示
- assets/cafe.jpg：店舗イメージ
- assets/coffee.jpg：コーヒーの仮写真
- assets/sandwich.jpg：ランチの仮写真
- assets/cake.jpg：スイーツの仮写真
- assets/placeholder.svg：写真が読み込めない場合の仮イラスト
- assets/leaf.svg：ファビコン
- README.md：確認方法・編集のポイント

写真の取得に失敗した場合は、対応するJPEGの代わりに仮イラストを表示します。

## 確認方法

1. このフォルダのindex.htmlをChromeやEdgeなどのブラウザーで開きます。
2. またはVS CodeのLive Serverでindex.htmlを開きます。
3. 開発者ツールのデバイス表示で、幅375px・768px・1440pxなどを確認します。
4. スマートフォン幅でメニューを開閉し、各リンクの移動先を確認します。Escapeキーでも閉じられます。
5. お問い合わせボタンでフォームを開き、必須項目とメール形式の検証、入力確認メッセージを確認します。
6. Tabキーでリンクや入力欄を移動し、フォーカスが見えることを確認します。

## 編集のポイント

- 店舗情報やメニューはindex.html内を編集してください。
- 配色や主な余白はstyle.css冒頭の:rootにまとめています。
- 画像はassets内のファイルを置き換えます。適切なaltテキストも編集してください。
- モバイルメニューの切り替え幅はCSSとJavaScriptの両方で820pxに設定しています。
- JavaScriptを無効にすると、ナビゲーションとフォームは最初から表示されます。フォームは操作できません。
- フォームの入力欄と送信ボタンは初期状態ではdisabledにし、イベント設定後にJavaScriptで有効にします。JavaScriptが無効でも内容を送信しません。

## デモの仕様

店舗・住所・駅名・営業時間・価格は架空の設定です。案内図も架空のもので、実際の地図へはリンクしていません。
お問い合わせフォームは入力確認までのデモです。入力内容の通信・保存は行いません。
実務で公開する場合は実際の店舗情報へ差し替え、フォーム送信先を別途実装してください。
